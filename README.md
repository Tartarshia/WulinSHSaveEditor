# 大侠立志传：本地存档修改器

用于 Steam 版《大侠立志传：碧血丹心》（AppID 1948980）的离线 Windows 本地网页存档修改器。

程序只在本机 `127.0.0.1:8765` 开启网页界面，存档和游戏数据不会上传到网络。自动寻路失败时，可直接在网页顶部输入游戏目录与存档目录。

功能包括：

- 背包道具按名称或 ID 搜索、按 ID 排序、按游戏物品类别筛选；修改数量或添加道具。
- 物品页默认隐藏武功秘籍、配方、消耗品、材料和珍宝，可通过各自的独立复选框显示。
- 消耗品、材料、珍宝各有顶级页：按游戏官方种类分组、品质排序和着色，显示队伍背包数量，支持搜索、已拥有/未拥有筛选和数量编辑（0 为移除）。未拥有指当前背包没有，不代表本周目从未获得过。
- 消耗品页提供“经验书 999”快捷按钮：将全部官方经验书各设为 999 本，含未拥有和筛选外条目；不影响其他消耗品，仍须保存后才写入。
- 从游戏自带数据表显示物品与角色中文名称。
- 所有物品页直接显示物品说明，无需展开：读取本机游戏资源中的中文原文，并补充表中装备要求、基础属性、使用条件和直接效果；配方页显示制作产物说明。缺失说明明确标注，不推测动态效果，也不随修改器分发游戏文本。
- 点击分类标题栏可折叠或展开整类内容（秘籍、配方、消耗品、材料、珍宝及生活技能），保留名称与数量；筛选、修改数量或切换页面时保留各分类的折叠状态。单件物品说明仍直接显示。
- 底部固定状态栏统一显示读取进度、加载完成、保存过程、保存结果和错误；长备份路径自动换行，不撑宽页面，原顶部加载提示框已合并至状态栏。
- 查看出战、已入队未出战、曾入队已离队角色，并修改基础属性、角色等级与经验。
- 角色列表限制为一屏内高度并独立滚动；宽屏下固定在右侧属性区旁，窄屏下避免遮挡属性内容。其他页面保持整页滚动。
- 非出战角色（含已入队未出战、曾入队已离队）显示所读存档记录的所在地，家园角色显示“家园 · 子区域”；缺少当前位置时仅标注“上次离队地点”，不误用复活点，不把所有未出战角色都猜成家园，也不改变角色位置。
- 编辑角色先天五维（体质、臂力、敏捷、悟性、福缘）的 1–10 级成长等级与经验，支持一键拉满当前角色，保留经验与后天加成；道德六维仅显示和编辑主角。
- 独立顶级页“生活技能”按采集、鉴定、制造、市井、生存分组，编辑主角 26 项能力的等级与经验；可按名称或分类搜索，等级上限来自游戏自带数据表。
- “生活技能”页支持“全满级”：全部能力设为各自游戏上限，对应经验清零；包含搜索筛选外的能力，仍需手动保存。
- 修改角色已学武功的等级与经验；名称和等级上限来自游戏自带数据表。
- 一键补齐尚未拥有的官方武功秘籍，每件一份；队伍背包、当前队员装备栏和个人背包均计入拥有，避免重复添加，并显示持有人。
- 修改主角的江湖历练经验池数值；上限读取自游戏自带常量表。
- 修改队伍铜钱、体力、心情，或一键补满体力与心情；体力上限会计算当前 Buff 加成。
- 一键解锁尚未学会的官方有效配方，不写入游戏表中标记为停用的配方。
- 将游戏内部存活天数向前推进（例如第 100 日）；不会直接修改 Steam 成就状态。
- 修改主角与已建立关系 NPC 的关系值，以及已生成势力的关系值（范围均为 -100 至 100）。
- 每次写入前完整备份存档槽；AES/GZip 编码后的内容会先回读验证，再原子替换原文件。

本工具不修改剧情、任务、入队状态或 Steam 成就。

## 使用

1. 完全退出游戏。
2. 运行 `启动大侠立志传存档修改器.cmd`，或从 Releases 下载 `WulinSHSaveEditor.exe`；浏览器会打开本机网页界面。
3. 工具会自动寻找 Steam 安装目录和存档目录；若找不到，在网页顶部填入目录后点击“确认目录”。游戏目录应直接包含 `Wulin.exe`，存档根目录应直接包含 `Save0`、`QuickSave0` 等文件夹。
4. 读取存档、修改内容并保存。备份位于存档根目录的 `_EditorBackups`。
5. 启动游戏验证。若 Steam Cloud 出现冲突，请确认选择刚修改的本地版本。

关闭最后一个修改器网页后，本机服务会在约 4 秒后自动退出；刷新网页或关闭其中一个页面（其他页面仍开着）不会结束服务。浏览器异常崩溃时，服务会在心跳中断约 3 分钟后退出。退出不会自动保存修改，请先点击相应页面的保存按钮。重复启动修改器会复用已有服务并打开页面。

选择过的目录只保存在本机 `%APPDATA%\WulinSHSaveEditor\config.json`，不会上传、不会写入本项目，也不会随发布包分发。

## 从源码运行或构建

需要 Python 3.11+：

```powershell
python -m pip install -r requirements.txt
python web_app.py
python test_public.py
python -m unittest test_browser_lifecycle -v
python -m unittest test_editor_stats -v
```

可选的浏览器界面回归测试（需要本机 Microsoft Edge，使用模拟数据，不读写真实存档）：

```powershell
python -m pip install -r requirements-test.txt
python -m unittest test_ui_browser -v
```

构建单文件 Windows 程序：

```powershell
.\build.ps1
```

构建产物为 `dist\WulinSHSaveEditor.exe`。
