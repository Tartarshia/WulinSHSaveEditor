# 大侠立志传：本地存档修改器

用于 Steam 版《大侠立志传：碧血丹心》（AppID 1948980）的离线 Windows 本地网页存档修改器。

程序只在本机 `127.0.0.1:8765` 开启网页界面，存档和游戏数据不会上传到网络。自动寻路失败时，可直接在网页顶部输入游戏目录与存档目录。

## 当前版本：v1.2.0（阶段完成版）

源码及本地版新增“状态”页（尚未发布新的 Release）：仅修改主角的普通状态。已获得置顶，未获得可按游戏表默认顺序、ID 或品质排序；支持永久／临时及来源筛选，依据官方角色创建特征表单列“创建角色可选”。卡片悬停或键盘聚焦显示游戏中文说明；对可核实的脚本状态标注触发条件与效果，从官方 SelfPropBufflData 表读取属性门槛（如好事成双需福缘 ≥ 10），这些状态由游戏自动管理并保持只读；原始标签限制仅在悬停说明中展示，未知条件明确标注未解析，且将触发条件与修改器只读限制分开说明。特殊、剧情、经脉、家园、条件联动、动态数值、内部隐藏和未知状态只读并显示原因；游戏内部隐藏状态默认不显示，可勾选“显示游戏内部隐藏状态”查看，不影响存档记录或其他只读状态。普通状态增删会同步调整可解析的属性缓存，临时状态按官方时长录入并由游戏继续计时；不补发创建时的金钱、道具、武功或其他奖励。修改仍需点击“保存状态”；该页与角色属性、生活技能共用角色存档文件。实际游戏内的效果和计时仍须验证。

从 [GitHub Releases](https://github.com/Tartarshia/WulinSHSaveEditor/releases/latest) 下载 Windows x64 压缩包，解压运行 `WulinSHSaveEditor.exe`，无需安装 Python。升级时先退出旧版的所有页面，再运行新版；未保存的内存修改不会迁移。不要在旧服务仍运行时只替换 EXE。

这一阶段包含独立生活技能、装备及宠物装备、其他可堆叠物品页面；完善物品分组、分类折叠、底部状态栏与角色列表滚动。装备支持每次新增独立一件、逐件删除、并列显示及附加数据弹窗。

已补齐 ModEditor 导出表遗漏的阅读典籍识别：从本机实际资源核对名称、品质、类型、典籍标签及可解析的直接效果，归入“消耗品 → 经验书”。未验证的其他未知条目仍保留原 ID，不猜测名称和效果。

功能包括：

- 背包道具按名称或 ID 搜索、按 ID 排序、按游戏物品类别筛选；修改数量或添加道具。
- 物品页默认隐藏武功秘籍、配方、消耗品、材料、珍宝、其他可堆叠物品和装备（武器、防具、饰品及宠物装备），可通过各自的独立复选框显示。
- 顶级页“其他（可堆叠）”收录游戏明确标记可堆叠的暗器、毒物、杂项及任务钥匙，另将任务类的三生石、三义香归入此页的杂项组。支持分组、品质排序着色、搜索、拥有状态筛选及数量编辑。非可堆叠物品和其他非钥匙任务物品仍保留在物品页；缺少可堆叠标记的不纳入。
- 消耗品、材料、珍宝各有顶级页：按游戏官方种类分组、品质排序和着色，显示队伍背包数量，支持搜索、已拥有/未拥有筛选和数量编辑（0 为移除）。未拥有指当前背包没有，不代表本周目从未获得过。
- 消耗品页提供“经验书 999”快捷按钮：将全部官方经验书各设为 999 本，含未拥有和筛选外条目；不影响其他消耗品，仍须保存后才写入。
- “经验书”分组同时收录属性调整类阅读典籍，例如商君书、秦皇刻石、秦律；部分会降低道德属性，并非全是增益。请先阅读显示的实际效果。“经验书 999”会覆盖该分组的全部条目，包括补全识别的典籍，但不会自动使用它们。
- 顶级页“装备”按拳套、剑、刀、枪、棍、扇、匕首、笔、琴、箫、琵琶等武器种类，以及防具、饰品、宠物武器、宠物防具、宠物饰品分组，组内按品质排序着色，支持搜索、品质和拥有状态筛选。仅统计队伍背包：每种装备始终保留“添加1件”卡片，已有装备也能新增独立一件（不堆叠、不覆盖），已拥有逐件确认删除，同名多件并列显示，附加数据通过“显示附加数据”按钮在独立弹窗内查看存档原值（不代表效果已生效），按钮为“添加1件／删除1件”，保留其他装备及其附加数据；不提供数量或属性编辑，不操作角色或宠物身上装备，修改后须保存。
- 从游戏自带数据表显示物品与角色中文名称。
- 所有物品页直接显示物品说明，无需展开：读取本机游戏资源中的中文原文，并补充表中装备要求、基础属性、使用条件和直接效果；配方页显示制作产物说明。缺失说明明确标注，不推测动态效果，也不随修改器分发游戏文本。
- 点击分类标题栏可折叠或展开整类内容（秘籍、配方、消耗品、材料、珍宝、其他可堆叠物品、装备及生活技能），保留名称与数量；筛选、修改数量或切换页面时保留各分类的折叠状态。单件物品说明仍直接显示，装备实例的附加数据通过弹窗查看。
- 底部固定状态栏统一显示读取进度、加载完成、保存过程、保存结果和错误；长备份路径自动换行，不撑宽页面，原顶部加载提示框已合并至状态栏。
- 查看出战、已入队未出战、曾入队已离队角色，并修改基础属性、角色等级与经验。
- 角色列表限制为一屏内高度并独立滚动；宽屏下固定在右侧属性区旁，窄屏下避免遮挡属性内容。其他页面保持整页滚动。
- 非出战角色（含已入队未出战、曾入队已离队）显示所读存档记录的所在地，家园角色显示“家园 · 子区域”；缺少当前位置时仅标注“上次离队地点”，不误用复活点，不把所有未出战角色都猜成家园，也不改变角色位置。
- 编辑角色先天五维（体质、臂力、敏捷、悟性、福缘）的 1–10 级成长等级与经验，支持一键拉满当前角色，保留经验与后天加成；道德六维仅显示和编辑主角。
- 独立顶级页“生活技能”按采集、鉴定、制造、市井、生存分组，编辑主角 26 项能力的等级与经验；可按名称或分类搜索，等级上限来自游戏自带数据表。
- “生活技能”页支持“全满级”：全部能力设为各自游戏上限，对应经验清零；包含搜索筛选外的能力，仍需手动保存。
- 修改角色已学武功的等级与经验；名称和等级上限来自游戏自带数据表。
- 一键补齐尚未拥有的官方武功秘籍，每件一份；队伍背包、当前队员装备栏和个人背包均计入拥有，避免重复添加，并显示持有人。
- 修改主角的江湖历练经验池数值；上限读取自游戏自带常量表。
- 修改队伍铜钱、体力、心情，或一键补满体力与心情；体力上限会计算当前 Buff 加成。
- 一键解锁尚未学会的官方有效配方，不写入游戏表中标记为停用的配方。
- 将游戏内部存活天数向前推进（例如第 100 日）；不会直接修改 Steam 成就状态。
- 修改主角与已建立关系 NPC 的关系值，以及已生成势力的关系值（范围均为 -100 至 100）。
- 每次写入前完整备份存档槽；AES/GZip 编码后的内容会先回读验证，再原子替换原文件。

本工具不修改剧情、任务、入队状态或 Steam 成就。

## 使用

1. 完全退出游戏。
2. 发布包用户：解压 Releases 的 Windows x64 ZIP，运行其中的 `WulinSHSaveEditor.exe`。源码用户：安装下文依赖后运行 `启动大侠立志传存档修改器.cmd` 或 `python web_app.py`。浏览器会打开本机网页界面。
3. 工具会自动寻找 Steam 安装目录和存档目录；若找不到，在网页顶部填入目录后点击“确认目录”。游戏目录应直接包含 `Wulin.exe`，存档根目录应直接包含 `Save0`、`QuickSave0` 等文件夹。
4. 读取存档、修改内容并保存。备份位于存档根目录的 `_EditorBackups`。
5. 启动游戏验证。若 Steam Cloud 出现冲突，请确认选择刚修改的本地版本。

关闭最后一个修改器网页后，本机服务会在约 4 秒后自动退出；刷新网页或关闭其中一个页面（其他页面仍开着）不会结束服务。浏览器异常崩溃时，服务会在心跳中断约 3 分钟后退出。退出不会自动保存修改，请先点击相应页面的保存按钮。重复启动修改器会复用已有服务并打开页面。

选择过的目录只保存在本机 `%APPDATA%\WulinSHSaveEditor\config.json`，不会上传、不会写入本项目，也不会随发布包分发。

## 从源码运行或构建

需要 Python 3.11+：

```powershell
python -m pip install -r requirements.txt
python web_app.py
python test_public.py
python -m unittest test_browser_lifecycle -v
python -m unittest test_editor_stats -v
python -m unittest test_status_editor -v
```

可选的浏览器界面回归测试（需要本机 Microsoft Edge，使用模拟数据，不读写真实存档）：

```powershell
python -m pip install -r requirements-test.txt
python -m unittest test_ui_browser -v
```

构建单文件 Windows 程序：

```powershell
.\build.ps1
```

构建产物为 `dist\WulinSHSaveEditor.exe`。

## 安全边界与验证

- 状态页默认隐藏临时状态和游戏内部隐藏状态，两个复选框可分别显示；筛选不会修改或移除存档状态。
- 选择存档后，所有修改先留在内存；只有点击对应页面的保存按钮才写入。关闭网页或退出程序不会自动保存。
- 写入前必须完全退出游戏。每次保存会先备份整个存档槽，再编码、回读校验并原子替换目标文件；还原时请在游戏和修改器都退出后使用 `_EditorBackups` 中的完整存档槽。
- 程序不解除剧情锁、不直接写 Steam 成就、不修改角色入队或结缘状态；关系与地点展示以所读存档为准，不是游戏实时状态。
- 发布前执行公开单元测试、浏览器模拟回归、ES3 编码回读测试和 Windows 构建，并检查发布包隐私。真实存档只用于读取验证，不随源码或发布包分发。
- 编码和回读通过不等于游戏内效果、DLC 剧情或 Steam Cloud 已验证。进游戏确认效果；遇到云冲突时谨慎选择本地修改后的版本。
